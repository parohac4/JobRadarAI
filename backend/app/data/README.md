# Lokality

`cz_places.json` obsahuje česká sídla z GeoNames, staženo 16. 11. 2026
z https://download.geonames.org/export/dump/CZ.zip (třída P, bez historických,
opuštěných sídel a částí měst). Sloupce: název, šířka, délka, populace,
kód kraje, kód okresu. Souřadnice představují centrum sídla, vzdálenost je vzdušná.

Zdroj: [GeoNames](https://www.geonames.org/), licence
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

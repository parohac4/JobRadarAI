# JobRadar AI – portfolio snippet

**JobRadar AI** is a self-hosted job search cockpit I built to automate collecting listings, scoring fit against a real professional profile, drafting responses, and tracking application state—without auto-sending applications.

**Stack:** Python/FastAPI, PostgreSQL, React/TypeScript, Docker Compose, Caddy, pluggable LLM (OpenAI or offline mock).

**Highlights:** duplicate detection across sources, prompt-injection-aware AI prompts, audit logging, demo mode with synthetic data, GitHub Actions CI, Czech UI with light/dark theme.

**Problem solved:** reduces manual copy-paste across job portals while keeping the human in control of every outbound message.
